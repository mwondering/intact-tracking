本轮实验将四肢负载改为 `{0, 1, 2, 4} kg` 的完整笛卡尔积，检验复用同一 DR 是否有利于 residual policy 利用 latent。

训练目录：`runs/limb_context_20260913_memory350_compressed_grid256_adaptive_scratch`。

原连续负载实验已按用户要求暂停。baseline 保存于 4500 轮，latent 保存于 3701 轮；各自的 `checkpoint_final.pt`、`checkpoint_interrupted.pt` 和采样状态均保留在 `runs/limb_context_20260913_memory350_compressed_ee_adaptive_scratch/ppo/` 下。两组均在完整更新结束后退出，四 rank 参数一致性检查通过。

新两组从零启动。baseline 使用 GPU 0–3，latent 使用 GPU 4–7，每卡 8192 个环境、每组共 32768 个环境。每卡包含全部 256 个负载组合，每种组合 32 个副本，因此每组训练中每种 DR 共 128 个副本。负载列顺序为左手、右手、左小腿、右小腿。

同一组合的副本还共享完整的静态 DR：躯干质量与 COM、足底摩擦、电机 armature 和编码器偏置。256 套参数由公共种子生成，跨四个 rank 以及 baseline/latent 两组相同。每个 world 的 motion、phase、初始状态、观测噪声、推力过程独立采样；各自维护 Memory350 历史。DR 在启动时固定，普通 episode reset 保留长期记忆。

Actor 仍使用 `1645→512→256→128`，拼接 64 维 latent 后进入 `192→256→128→29`；critic 使用 `6330→1024→512→256→128`，拼接 latent 后进入 `192→256→128→1`。baseline 的 64 维槽置零。DR 分组编号仅用于诊断索引，没有作为额外策略或价值输入。Encoder 与其归一化保持冻结，predictor 不参与 PPO。两组从第一轮直接 adaptive，保留原始末端高度终止，训练没有轮数上限。

每次 PPO 更新记录以下诊断，固定接收方的当前观测，只替换 latent：

- `latent_same_dr_action_delta_rms`：替换为同 DR 的另一个独立 world 的 latent。
- `latent_cross_dr_action_delta_rms`：替换为不同 DR world 的 latent。使用固定的随机无不动点排列，避免网格相邻组合造成系统性的近邻偏差。
- `latent_cross_dr_to_residual_rms`：上述动作变化相对 residual 动作 RMS 的尺度。
- `latent_same_dr_distance`、`latent_cross_dr_distance`：对应 latent 的平均 L2 距离。

这些诊断测量动作敏感性，不直接等于 latent 带来的控制收益。继承的 `latent_shuffle_action_delta_rms` 仍使用 world 维度平移，在离散网格布局下的 donor 分布与旧连续采样实验不同，不作为两轮实验唯一的使用率比较依据。

每 100 轮保留原来的 512 motion 固定端点评测：四肢全 0 / 全 4 kg，各自 cold / warm500。评测中的其他 DR 仍按原来的独立连续协议和固定种子生成，用于检查对训练参数表之外环境的表现。

每 1000 轮增加 128 motion、每个 motion 两个相同起点的独立 DR world 的闭环评测。两组都测正确输入；latent 组额外测同 motion、同 phase 的跨环境 latent 交换。四肢负载及其他 DR 使用独立连续样本，warmup 为 frozen tracker 的 500 步，最多评测 1000 步。交换仅在双方仍有效、短历史完整且参考 phase 相同的时候发生，报告实际交换覆盖比例。body/joint 比较使用共同有效前缀和按 motion 重采样的置信区间；失败率、覆盖率同步报告。新评测只在所属四卡 PPO 暂停时运行。

上线前通过 42 项测试和两组四卡真实训练测试（每卡 512 环境，5 次 PPO 更新）。8 个 rank 的静态参数表一致，训练及 episode reset 后参数表未变；两组初始 actor / critic 可训练权重相同、优化器为空、latent 输入权重在实际 PPO 中更新。8 motion 的闭环评测测试验证了 checkpoint、物理参数、起点配对和交换流程。源文件快照、测试证据及哈希保存在训练目录的 `PPO_READY.json`、`smoke_verification.json`、`usage_smoke_verification.json` 和 `ppo_source_snapshot/`。

本次同时改变了负载取值分布和静态 DR 参数的复用数量。与旧实验比较反映这套采样方案的总体效果；不能将所有差异单独归因于副本数量。离散负载单肢平均为 1.75 kg，旧 `U(0,4)` 平均为 2 kg；全零组合占 1/256，也不等于 encoder 阶段的 nominal50。
