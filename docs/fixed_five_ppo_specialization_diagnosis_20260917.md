# 为什么强弱分档专家没有整体超过混训

依据：当前 1000 轮训练代码、实际 16,384 个环境参数、u300/u1000 的相同 512 环境配对评测。参数与 batch 审计保存于 [audit.json](../runs/limb_context_20260917_fixed_five_ppo_full_4x4096/specialization_diagnostic/audit.json)。以下区分已验证事实与尚未建立因果关系的解释。

## 专家的上限与这次 PPO 找到的策略不同

每个专家和 baseline 的 actor 架构、观测及冻结 tracker 相同。把 baseline actor 权重复制给任意专家，就能在该类执行相同策略。因此专家的可表示策略集合包含当前 baseline，并不存在必须比 baseline 差的结构性下限。独立 PPO 使用有限样本、固定更新预算，未必优化到这个上限。

这次从共同的冻结 tracker 出发，但 residual 初始输出为零，critic 的 `initial_checkpoint=None`。四套可训练 residual 与 critic 独立学习；没有先学一个混合 residual/critic，再分支微调。

## 每一类仍是宽分布

分类是 100 秒冻结 tracker 交互得到的环境平均 latent 到 nominal 中心的标量距离，分为四档。不是按补偿动作、最优策略或策略梯度冲突分组。

实际 C3 的四项负载分别仍从零延伸到各自上限：手约 2.5 kg、小腿约 4 kg；COM xyz 都覆盖近似 ±7.5 cm，摩擦约 0.302–2.000。COM x 负偏移、正偏移、零分别占 23.38%、32.92%、43.70%。这些是各轴边际范围，不表示任意极值组合均在 C3 内。

四类的手部负载平均值有明显区别，但小腿负载和多个其他 DR 仍广泛重叠。即使强弱分类完全可靠，也不保证组内环境要求相似的修正动作。每个专家仍在解决一组 DR 下的泛化问题。

## 数据共享与独立优化的代价

| PPO | 环境数 | 每轮 transition | 全局 minibatch | u1000 累计 transition |
|---|---:|---:|---:|---:|
| C0 | 1771 | 42504 | 10626 | 42504000 |
| C1 | 955 | 22920 | 5730 | 22920000 |
| C2 | 8534 | 204816 | 51204 | 204816000 |
| C3 | 5124 | 122976 | 30744 | 122976000 |
| baseline | 16384 | 393216 | 98304 | 393216000 |

五套 PPO 都进行 1000 轮、每轮 5 epochs × 4 minibatches，即 20000 次 optimizer 更新，actor/critic 学习率都固定为 1e-4 / 5e-4。C1 的 minibatch 只有 baseline 的约 1/17.2。相同超参数不保证不同 batch 与任务分布的优化效果相同。

关键限定：baseline 在某一类上获得的 transition 数与对应专家相同；不是 baseline 在该类获得了 17 倍样本。baseline 额外使用其他类别的数据来更新同一套 residual 和 critic。若跨类存在可共享的修正和价值规律，这些样本可能帮助当前类；独立训练切断了这种迁移。反过来，只有分组确实减少了有害的任务冲突，独立训练才更容易抵消共享学习的损失。当前没有测过跨类梯度是否冲突，不能把正向迁移当成已证实原因。

无 DR latent 输入也不等于策略不能根据响应调整动作。1645 维 tracker 特征含运动参考、身体运动学、本体感知历史和估计信息，还向 residual 提供当前 tracker 动作；baseline 可以学习依赖状态的修正。

## Body 指标收益不是全局轨迹收益

u1000 双方共同存活时段的总体变化：

- 对齐参考的 body 位置误差：expert 低 2.14%。
- 未对齐世界坐标 body 位置误差：expert 高 0.15%。
- Joint 位置误差：高 2.37%。
- Joint 速度误差：高 3.97%。
- Body 角速度误差：高 3.24%。
- 总 reward：相差 -0.0026%，接近持平。

前面的 body 改善支持局部姿态/位置跟踪收益，不能单独解读成整体轨迹质量提升。总 reward 包含多个追踪、平滑、接触等项；上述误差有取舍，但缺少逐 reward 项累计值，尚未定量分解每项对 reward 差异的贡献。

## 实现检查与未验证项

已检查各专家只使用自己行为产生的轨迹、GAE 和 bootstrap；baseline 独立交互；不同 rank 样本数的梯度加权、各专家内优势统计/critic 归一化同步，以及模型保存 hash 一致。固定分类和物理参数不变，reward/actor 架构一致。没有在这些检查中发现直接解释结果的实现错误，但这些检查不证明 PPO 优化充分。

当前日志未记录实际 KL、clip fraction、按类别的 critic explained variance 或优势估计准确性。不能把不同任务分布上的 value loss 大小直接当成 critic 优劣，也不能据此认定 actor 或 critic 是唯一原因。C3 有 5124 个环境，仍然落后，因此小类别样本量不能单独解释全部现象。

更有判别力的后续对照是：从已训练的混合 baseline 复制 actor、critic、动作分布和归一化状态，再让四份策略按固定类独立 on-policy 微调。这样起始策略相同，可以更直接检验分类后的专门化是否带来额外收益，同时记录实际 KL、clip fraction 和 critic 拟合质量。本次仅进行诊断，没有启动该训练。
