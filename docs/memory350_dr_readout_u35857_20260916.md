**当前 u35857 的 latent 能否恢复 DR 参数**

2026-09-16。结论：已有部分物理参数可以从 latent 通过线性标定近似恢复，尤其是四肢负载、躯干 COM 和足底摩擦。此次线性读出对躯干质量变化、29 个关节 armature scale 的效果很弱；这不证明它们完全不存在于 latent，也不支持“全部 DR 已被完整编码”的说法。

“线性读出”是冻结 encoder，在单位化的 64 维 latent 后拟合 `theta_hat = W @ z + b`。例如预测四项负载时，W 是 4×64，每个负载由多个 latent 分量加权求和得到。它需要真实仿真参数作为标定标签；标定完成后的计算只需要 latent。该操作检验信息是否容易提取，不要求 latent 的单个坐标对应某个物理参数，也不是 PPO 策略已利用这些信息的证据。

**补测对象与方法**

使用当前 temporal29 Transformer 训练配置指定的冻结 context `update_035857.pt`，SHA-256 为 `3c489cf5457889bf88441175ec4f10f4448104f44f7914eaaf762a9c3659d8f7`。此次只在 CPU 上读取 checkpoint、重编码既有历史、拟合诊断读出；未修改正在训练的 policy、encoder 或 router。

缓存来自原 u1500 采集、u30750 审计的 LaFAN 冻结 tracker 轨迹，包含原 tracker 背景 DR 和四肢独立负载，手部 0–2.5 kg、小腿 0–4 kg。32 个原始历史文件重新编码，共 16384 个快照；评分仅使用完整 Memory350 历史，得到 278 个可用 world 和 2704 个 query。全部原始历史及 physics 文件哈希校验通过。

同 world 的参考 motion 窗口先逐个归一化 latent，再求均值作为读出拟合输入。query 来自另一组 motion family，原始历史与参考历史不重叠。按完整 world 做固定五折，seed=20260916，将打乱后的 world ID 用 array_split 分成五份。每折只用其余 world 的参考原型和真实参数拟合，测试时输入留出 world 的单窗口 latent。

拟合使用带截距的岭回归：平均平方残差加 0.1 倍权重平方和，截距不正则化；特征均值与标准差仅来自拟合 world，不搜索超参数，不裁剪物理预测。38 项输出分别对应缓存中保存的真实参数，未包含 encoder bias。新脚本首先逐项复现旧 u30750 的四项负载 R²，并校验 source_row、world fold；保存预测随后独立重算了全部 38 项 R² 和 MAE。

当前重编码使用 CPU FP32，旧缓存和实际 PPO context 使用 CUDA BF16。以下数值是当前权重的离线读出诊断，不应把与旧报告的小差异全部归因于继续训练。

**对分专家的含义**

当前 encoder 的训练已经用 DR 中心距离关系和同环境跨 motion 正样本约束 latent，因此存在一定环境结构有训练依据；损失并不直接保证所有真实参数都能反演。相关实现见 [memory350_dr_centers.py](../src/intact_tracking/memory350_dr_centers.py)。

对于当前只随机化负载的任务，可以把“latent → 标定后的四项负载估计 → 专家类别”作为可解释的路由候选。也可以沿用 [按稳定环境原型聚类的方案](latent_partition_specialists_20260916.md)，但须实测每个簇是否对应适合共用策略的环境。线性可读出性与原始 latent 的欧氏聚类是不同问题；一个 latent 可以很好地编码负载，同时其聚类边界主要受 COM 或摩擦影响。

此次仍未覆盖当前 load-only PPO 的实际轨迹、Memory350 未填满时的估计、全部 motion、新专家动作造成的分布变化及闭环切换。正式接入前应在实际分布上标定并留出 world 评估，再比较固定正确类别与在线路由的控制收益。对读出很弱的参数，不应默认 latent 已能够支持可靠的细分专家。

**连续 latent 路径的含义**

对固定的线性读出，若输入路径 z(t) 连续，`theta_hat(t) = W @ z(t) + b` 必然连续。这里的 z 是读出实际接收的单位化 latent。若直接对两个单位 latent 做直线插值，直线内部通常不再是单位向量；再次单位化后，预测参数仍可连续变化，但不再保证按同一比例线性变化。

这种读出连续性是映射形式的数学性质，不能证明路径中的每个点都由真实环境产生，也不能保证映射一一对应、物理参数单调变化，或把预测参数设置到仿真后得到的 latent 会回到原路径。当前模型是历史到表征的 encoder 和动力学 predictor，没有已经验证的“任意 latent → 唯一完整物理环境”的逆模型。

现有固定 world 数据也直接显示 motion/history 引起的波动：270 个 world 各有至少两条留出 query，共 2696 条，真实 DR 在各自 world 内逐项完全相同。对每个 world 分别计算负载预测在这些 query 上的标准差，再对 world 取中位数，左手/右手/左腿/右腿依次为 **0.0805 / 0.0658 / 0.1755 / 0.1775 kg**。对应最大最小差的中位数为 **0.2617 / 0.2216 / 0.5740 / 0.5639 kg**。这些是不同 motion/history 的稀疏快照，不是逐控制步抖动或真实 DR 变化。[完整波动统计](../runs/limb_context_20260916_dr_readout_u35857/fixed_world_readout_variation.json)。

要验证物理对应，可先固定其他 DR，对负载参数按连续网格取值，分别在匹配 motion 和独立、完整历史下采集 latent，检查真实参数、读出参数以及环境原型轨迹是否一致。若参数在同一次 rollout 中随时间改变，还需单独评估 Memory350 的历史滞后及 physics-session 清空行为；静态 world 的本次读出不能替代该动态适应实验。实际专家训练仍应从可执行的物理 world 采样并建立稳定原型，再按 latent 结构分组。
