# 每肢独立半零负载：16384 个环境、每环境 50 秒

本轮已经完成 mjwarp GPU 实测。新采样显著增加了近 nominal 距离档的覆盖，并形成随档位上升的平均负载梯度。仍未实现八档等概率；小腿大负载也仍可能进入较近档。

每条肢体独立以 50% 概率无附加负载，否则采用原均匀分布：左右手各 U(0,2.5) kg、左右小腿各 U(0,4) kg。复用上一轮已抽取的 16384 组新规则参数，背景 DR 与原采样逐项相同。四肢同时零负载为 1007 个环境，其他背景 DR 仍然存在。

8 GPU 分片、每 DR 环境 2500 控制步，dt=0.02 秒，共 50 秒；冻结原 tracker 和 response10/u15000，不训练网络。每 100 步查询一次，仅完整 short50+long30 历史参加汇总，共 340128 个有效 DR 查询，每环境 17–22 个，平均约 3.17 个不同 motion。物理参数始终固定，保留原有 motion/episode 重置和背景扰动。另有 2048 个 nominal 对照，不计入 DR 样本统计。

环境中心定义为 `mean_t(unit(z_t))`，中心距离为 `||环境中心 - 固定 nominal 中心||₂`，不再次归一化中心。固定八档边界为旧十六档两两合并。每环境只归入一个档；旧采样记录同样截取前 50 秒，避免将 50 秒和 64 秒混在一起比较。

较近四档 C0–C3 从旧采样的 37 个（0.23%）增加到 1409 个（8.60%）。最大单档占比从旧 C6 的 77.55% 降低到新 C5 的 42.07%，但 C5+C6 合计仍为 81.41%，距离每档 12.5% 还有明显差距。

在新数据中，随机取一个总负载 <2 kg 的环境和一个 >8 kg 的环境，重载中心更远的概率为 98.24%。所有 373 个 >8 kg 环境都进入 C5–C7，其中 357 个进入 C6–C7。C0 中 91.09% 环境的总负载 <2 kg。

这证明当前记录有粗粒度的轻重载分流，但不能声称采样改变提升了 encoder 的分辨能力：encoder 没有更新，旧数据相同排序指标已经是 98.90%。本次主要收益是近端环境覆盖和负载组合多样性。中等负载和背景 DR 的影响仍存在较多重叠。

小腿负载的近端案例：

- C0 的最大负载环境 world 301002，中心距离 0.1564；双手均为 0，双小腿分别为 2.033 和 2.136 kg，总计 4.169 kg。
- C2 的最大负载环境 world 500832，中心距离 0.6770；双手均为 0，双小腿分别为 3.835 和 2.829 kg，总计 6.664 kg。
- 仅手部有负载的 3064 个环境，平均总负载 1.67 kg，中心距离中位数 1.427；仅小腿有负载的 3159 个环境，平均总负载 2.68 kg，中心距离中位数 1.238。这是随机背景下的组间描述，尚非控制总质量与动作后的因果比较。

全零负载环境的中心距离中位数仍为 1.067；其背景 COM、摩擦等参数并未恢复 nominal。不能用“四肢无负载”代替“完整 nominal”。

旧口径 `mean_t(||unit(z_t)-nominal_center||)` 的新八档数量为 `[285,188,315,524,1245,6466,7085,276]`，轻重载排序概率 98.56%。它与中心距离分档有 91.91% 的逐环境一致率，主要结论不依赖这两种汇总方式的选择。

实际物理参数与新采样表逐项一致、全程不变。独立重放 512 份原始历史，unit latent 最大 L2 数值误差约 2.92e-7；全部 16384 个环境都有唯一记录，中心距离和类别用独立公式复核通过。占卡程序已按用户授权终止，采集及验证进程均已结束。
