# Memory350 是否发挥作用：2026-09-10 实测

结论：**长期 memory 已经为当前阶段一模型提供有效预测信息，尤其能补充 reset 后
不足的短期历史。尚不能据此断言新版优于旧 context200，或能够提高 PPO 表现。**

## 同一个 checkpoint 的配对消融

固定 `stage1_8192/update_007500.pt`（7500 updates / 30000 optimizer steps），
冻结全部参数，使用原来保存的四 rank 普通验证 batch，共 2048 个窗口、489 个物理
world。这些 world 不参与训练和归一化估计。保持短期历史、当前状态、动作、目标和
predictor 权重完全一致，只干预长期 memory。未重启或修改训练。

| 输入方式 | 五步 DR NMSE（汇总样本） | 相对正确 memory 的误差 | 按 world 配对 bootstrap 的 95% 区间 |
|---|---:|---:|---:|
| 正确的长期 memory | 0.027645 | 1.000× | — |
| 屏蔽长期 memory，仅保留原有短期输入 | 0.049514 | 1.791×（+79.1%） | 1.597–2.005× |
| 换成其他 world 的长期 memory | 0.059074 | 2.137×（+113.7%） | 1.878–2.428× |

错配时严格保留每个接收样本的 chunk 数和 padding mask；2048 个样本均成功找到
同 chunk 数的其他 world。四个 rank 的结果方向一致，屏蔽 memory 的误差分别为
正确 memory 的 2.099 / 1.749 / 1.569 / 1.875 倍。

两个数值校验通过：

- 自然输入的四 rank 平均 NMSE 为 `0.0276934616`，原训练日志为
  `0.0276934621`，相对差异约 `1.7e-8`。表格采用全体样本汇总，与训练日志的
  四个 rank NMSE 取平均略有区别。
- 原本没有长期 memory 的 297 个窗口作为负对照：屏蔽或错配后的预测误差与原值
  **逐元素完全一致**。

另一个固定 positive-pair 验证集合（2048 窗口、491 个 world）也复现相同方向：
屏蔽 memory 为 1.862×，错配为 2.246×。两个集合可能重叠，不能视为独立重复实验。

## reset 后的收益更强

| 样本组（均有长期 memory） | 窗口数 | 屏蔽 memory 后误差倍数 | 错配 memory 后误差倍数 |
|---|---:|---:|---:|
| 短期历史不足 50 步 | 931 | 2.501× | 2.930× |
| 其中不足 10 步 | 327 | 3.010× | 3.143× |
| 其中 10–24 步 | 312 | 2.197× | 2.774× |
| 其中 25–49 步 | 292 | 2.046× | 2.801× |
| 短期历史完整 50 步 | 820 | 1.697× | 2.339× |

在“不足 50 步且有长期 memory”的样本中，当前短期窗口尚未产生可移入长期区的
溢出交互，因此长期内容来自短期历史被 reset/运动切换清空之前。这组结果直接支持
跨 reset 保留交互历史的用途。该组屏蔽 memory 后误差比的 world bootstrap
95% 区间是 2.169–3.026×；97.5% 的窗口使用正确 memory 时误差更低。

当前训练 batch 的长期 memory 可用率为 100%，四 rank 在线 memory bank 已填满
30 段。固定普通验证集合来自启动阶段，长期可用率只有 85.50%，完整 30 段的比例
34.52%；因此下面单独考察完整 30 段的样本。

## 长度 scaling：有收益，但边际收益递减

固定同一批原本有完整 30 段长期 memory 的 707 个窗口，始终保持短期 50 步输入
不变，只保留长期区最新若干完整 chunk：

| 保留长期内容 | 五步 NMSE | 相对完整 300 步的误差增幅 |
|---|---:|---:|
| 0 步 | 0.050932 | +144.28% |
| 10 步 / 1 段 | 0.028794 | +38.10% |
| 50 步 / 5 段 | 0.023775 | +14.03% |
| 100 步 / 10 段 | 0.022125 | +6.12% |
| 200 步 / 20 段 | 0.021380 | +2.54% |
| 300 步 / 30 段 | 0.020850 | 参考 |

200→300 步仍有可测改善；200 步相对 300 步误差比的 95% 区间为
1.008–1.058×。这是当前按 300 步训练的 checkpoint 在推理时截断的结果，不能
替代分别按各个长度从头训练的 scaling 实验。

## 与旧 context200 的差异

两个版本都具有 64 维 latent 和同规模 predictor。旧版直接编码同 episode 的
最多 200 步历史；新版编码同 episode 的最近 50 步，加上不重叠、可跨 reset 的
30×10 步，长期经过分段编码及第二级 attention 得到一个 memory token。

| 设置 | 旧 context200 | 新 Memory350 |
|---|---|---|
| DR | 四肢 U(0,4) kg 负载配置 | 冻结 tracker 原有 DR + 四肢 U(0,4) kg |
| 每卡 A 环境数 | 1152（1024 训练 + 128 验证） | 8192（8064 训练 + 128 验证） |
| episode 上限 | 500 步 | 1000 步 |
| 关系项有效权重 | 0.01 | 0.02 |
| response_distance_scale | 1.0 | 0.75 |
| 模型总参数量 | 19,513,110 | 20,095,126（+2.98%） |
| 同 episode 完整历史作为表征学习门槛 | 需要完整 200 步 | 有可用短期或长期历史即可 |

两个版本优化 batch 都为每 rank 1024，全局 4096，每 update 四次优化。但新版
采集的交互量更大，验证物理环境和状态分布不同。7500 updates 时累计交互量约
1.751 亿和 12.450 亿，也不属于等采样预算比较。

| 各自固定验证集，均为 7500 updates | 旧 context200 | 新 Memory350 |
|---|---:|---:|
| 单步 NMSE | 0.038109 | 0.037904 |
| 五步 DR NMSE | 0.017117 | 0.027693 |
| latent 打乱后的误差倍数 | 1.770× | 2.516× |
| latent 距离与响应距离相关系数 | 0.357 | 0.443 |
| 同 world 相邻正样本 latent cosine | 0.9979 | 0.9780 |

新版五步指标当前更高，不能报告“新版预测整体优于旧版”。latent 打乱指标反映
整个 64 维 latent 的贡献，包括短期与长期；相关系数和 cosine 还受到损失权重、
尺度及验证样本门槛变化影响，也不构成 memory 独立收益的证明。真正支持 memory
有用的是上方固定同一模型、同一批样本的长期 memory 干预。

旧普通训练 batch 完整 200 步比例近期约 7.1%；四 rank 普通验证集合平均为
4.20%。旧表征 probe 则只选完整 200 步的正样本。新版普通验证短期完整率为
41.46%，长期可用率为 85.50%，并允许不完整短期历史参与表征学习，缓解了旧版
表征学习覆盖率低的问题。

## 判断范围及下一步

1. 已有直接证据：memory 被模型读取，正确内容能改善预测，reset 后作用更强。
2. 尚未证明：memory latent 只包含物理参数，而不包含 motion 信息。跨 world
   错配也改变了 motion 历史；现有 nominal 响应监督本身依赖状态和动作。
3. 尚未证明：新版优于相同配置下从头训练的无 memory 模型，或能够提高 residual
   PPO 表现。推理时突然屏蔽分支有分布变化，应通过匹配 DR、环境数、episode
   上限、损失权重和采样预算的独立训练对照检验训练收益。

建议保留当前 memory 结构。后续严格对照优先使用相同 50 步短期输入的无长期
memory 版本；当前阶段一持续训练，是否进入阶段二仍由用户判断。
