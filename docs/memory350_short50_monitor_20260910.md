# Memory350 / Short50：4500 轮副作用监测

2026-09-10，针对用户“长期历史会不会反而有负作用”的追问，补充同轮次预测评估和冻结权重干预。

**当前整体预测几乎持平；长期信息可用时有收益，长期信息为空时存在明显退化。**
不能用整体平均值宣布 Memory350 已经取得稳定净收益，也不能把空 memory 分组的退化解释成某段旧历史直接干扰预测。

## 同一 4500-update checkpoint、同一验证样本

两组均为从头训练，各完成 18,000 optimizer steps。归一化、DR、验证输入和目标保持一致。
共 2048 窗口、489 验证 world；以下 NMSE 合并全部 rank，百分比均为 **Memory350 相比 Short50**。
负值表示 Memory350 更好，正值表示更差。各分组含有重叠子集。

| 分组 | 窗口数 | Memory350 NMSE | Short50 NMSE | Memory350 误差变化 |
|---|---:|---:|---:|---:|
| 全部 | 2048 | 0.032704 | 0.032730 | −0.08% |
| 长期历史可用 | 1751 | 0.028128 | 0.032785 | −14.20% |
| 短期不足 50 步、长期可用 | 931 | 0.026119 | 0.033712 | −22.52% |
| 短期不足 10 步、长期可用 | 327 | 0.026480 | 0.038497 | −31.21% |
| 短期完整 50 步、长期可用 | 820 | 0.031544 | 0.031210 | +1.07% |
| 长期历史为空 | 297 | 0.056227 | 0.032447 | +73.29% |

长期为空分组的 95% world 配对 bootstrap 区间为 **+39.48% 至 +131.33%**，
其中 90.57% 的窗口 Memory350 误差更高。长期可用分组的区间为 −19.04% 至 −9.87%。
整体和短期完整分组的区间均跨越无差异点，尚不能区分优劣。
这些区间不包含训练种子之间的不确定性。

最近 10 个验证点（3600–4500）的平均误差，Memory350 比 Short50 低 0.38%；
7/10 个点较低，优势很小且有反复。相邻 checkpoint 高度相关，不作为独立重复实验。

按已有长期 chunk 数分组，1–5 段时 Memory350 点估计高 9.10%（区间跨零），
6–10 段基本持平，11–20 / 21–29 / 30 段时分别低 16.42% / 23.62% / 22.55%。
各长度分组的 motion 和短期完整率不同，这个分层结果本身不能单独证明长度的因果效果。

### 为什么短期不足 50 步的组 NMSE 反而更低

进一步核对同一 4500 轮逐窗口结果发现，Memory350 在短期不足组的共同尺度预测
MSE 实际上更高；更低的是除以该组无变化预测基线后的 NMSE。

| 有长期记忆的样本组 | 预测 MSE | 保持当前状态不变的基线 MSE | NMSE |
|---|---:|---:|---:|
| 短期不足 50 步 | 0.468568 | 17.939606 | 0.026119 |
| 短期完整 50 步 | 0.377888 | 11.979597 | 0.031544 |

这里的 MSE 已按两组共享的 `delta_std` 对各状态维度统一尺度，并非以米或弧度为
单一单位的物理误差。NMSE 再将每组预测 MSE 除以该组的无变化基线 MSE。
不足组的预测误差高约 24%，但基线误差高约 50%，所以比值更低。

两组不是同一批输入：motion、reset 阶段、状态变化不同，长期段数平均也不同
（22.73 / 19.31 段）。因此较低的分组 NMSE 不表示减少短期历史会改善预测。
此前的 −22.52% 是在同一不足组内比较 Memory350 和 Short50，两个模型的
NMSE 分母相同，这个配对改善不受上述跨组分母差异影响。

原始核验：`runs/limb_context_20260910_short50/comparison/monitor_20260910/short_length_group_normalization_audit.json`。

## 相对退化集中在长期为空的样本

| Update | 空长期时 Memory350 相对误差 |
|---:|---:|
| 500 | +2.23% |
| 1000 | +8.90% |
| 3000 | +51.01% |
| 4500 | +73.29% |

这里的“退化”是相对 Short50：Memory350 该组误差从 3000 轮的 0.05825 降到
4500 轮的 0.05623，但 Short50 从 0.03857 降到 0.03245，差距扩大。

现有训练日志从首次记录到 4500 轮，`batch_long_available_fraction` 均为 1.0。
该字段是 rank 0 在报告时最后一个训练 batch 的统计，**不是所有优化 batch 的完整审计**。
四 rank 平均的在线 memory 可用率也始终为 1.0。训练先采集 500 步预热，而 memory
跨 reset 保留，参数改变清空计数为 0；这支持“无长期输入的训练覆盖不足”这一解释。

模型实现中，长期为空时最终 attention 的 memory token 被 padding mask 屏蔽。
因此该组没有一段有效旧历史参与注意力。更符合现有证据的解释是：训练形成了对长期
信息的依赖，而缺信息时的短期路径没有得到充分训练；仍需单独的受控训练验证原因。

这批固定验证集来自启动采集，长期为空占 14.50%，不能把这个比例当作长期部署中的
出现频率。真实冷启动、参数变化后清空 memory 等场景仍需要模型具备相应能力。

## 冻结 Memory350 4500 轮权重，直接干预长期输入

自然输入复现训练日志（相对差约 5.7e−8），并与上述双模型评估的逐窗口预测对齐。
以下误差变化相对 **同一个 Memory350 的自然输入**，不是相对从头训练的 Short50。

| 样本组 | 屏蔽全部长期 | 错配其他 world 的长期 |
|---|---:|---:|
| 全部窗口 | +55.84% | +88.18% |
| 已有长期信息 | +77.55% | +122.47% |
| 短期不足 50 步且有长期 | +103.06% | +144.70% |
| 短期完整 50 步且有长期 | +41.63% | +91.18% |

原本长期为空的样本，屏蔽/错配前后预测逐元素一致。对已有长期信息的样本，95.09%
的窗口在屏蔽 memory 后误差上升。因此当前权重确实在利用长期信息，直接移除它无法
恢复从头训练 Short50 的表现。

对原本完整 30 段的相同 707 个窗口，保留最近 20 段或 10 段使误差分别上升 2.83%
和 6.97%，当前冻结权重下也没有发现缩短长期输入能改善平均预测的证据。
推理时的遮蔽不等价于重新训练一个更短 memory 的模型；错配也同时改变 motion 历史。
