# 144000-exp-heavy：负载质量与质心的 context 训练

本实验继承上一轮 proprio122 Memory350 的结构及全部 loss 系数。冻结 `checkpoint_144000.pt`，context encoder 与 forward predictor 从零初始化；不启动新的 residual PPO。

## 数据与环境

- 数据根目录为 `/data_zcy/wxy/motion_data_correct`，按 144000 的原始 8 份排除报告过滤：224651 条中保留 220480 条，各 rank 加载有序清单的 `files[rank::8]`，每卡 27560 条。
- 8 卡，每卡 16384 个主采集环境，总计 131072；每卡的 128 个验证环境包含在其中。沿用独立 nominal counterfactual B 仿真。
- 每卡保留 `ceil(16384 × 0.1) = 1639` 个严格 nominal 环境，其余 14745 个使用原 tracker DR，并附加四肢负载。
- 每个世界的物理参数只在构建时采样一次，motion/episode reset 不重采样。Stage 1 motion 均匀采样。

## 负载采样及合成动力学

四肢顺序为左手、右手、左小腿、右小腿，质量上限分别为 2.5、2.5、4、4 kg。每个范围划分为 4 个等宽区间，笛卡尔积形成 256 组。每组内四肢质量独立连续均匀采样，不共享一组固定物理参数。

每卡每组分配 57 或 58 个 DR 世界，余数跨 rank 轮换；全局 56 组各 460 个、200 组各 461 个。组编号在本卡 DR 世界之间随机打乱，其他原始 DR 的采样方式不变。

144000 的 torso COM 是 **xyz 独立均匀采样，每轴 ±7.5 cm**，没有球形限制。新增负载沿用此采样方式，但保留用户指定的 **每轴 ±5 cm**：以原负载挂载点为中心、使用所在连杆局部坐标系，构成立方体，最大偏移为 `sqrt(3) × 5 cm ≈ 8.66 cm`。torso 的 ±7.5 cm 范围不变。

手部挂载点为 wrist-yaw link 的 `(0.12, 0, 0)` m，小腿为 knee link 的 `(0, 0, -0.15)` m。负载尺寸沿用手部 `(0.10, 0.08, 0.08)` m、小腿 `(0.10, 0.08, 0.10)` m。将原连杆和长方体负载的伪惯量矩阵相加，得到合成质量、COM、主惯量和主轴方向，包含完整平行轴项。没有新增碰撞几何。

## 监督与不变项

新增监督只包含 **4 个质量和 12 个 COM 坐标**。惯量由这些变量和固定形状决定，仅用于物理仿真与一致性核验，不另加监督或参数预测头。原有 92 维 DR 监督保留，总计 108 维。标签仅监督 latent 距离，不作为 encoder 输入。

DR 距离沿用范围归一化与物理因素均衡：原 8 组，加上 4 个质量组和 4 个 COM 向量 RMS 组，共 16 组等权。每个 COM 组的 xyz 坐标均分该组权重。这是新增物理因素后的距离定义；原有损失系数不变。

| 损失项 | 系数 |
| --- | ---: |
| Teacher forced prediction | 1 |
| Recursive prediction | 0.5 |
| Local positive | 0.01 |
| Nominal A/B response relation | 0.1 |
| Cross-motion weak positive | 0.008 |
| DR soft neighborhood | 0.02 |
| Nominal anchor | 0.08 |

保持短记忆 50 步、长记忆 30 个互不重叠的 10 步片段、64 维 latent、原 predictor 与独立的 noisy proprio122 encoder 输入。每卡 batch 1024、microbatch 256、每更新 4 次优化，BF16；不因环境数增大调整学习率或损失权重。

16384 环境的显存验证发现，原来全部驻留 GPU 的跨 motion 原始历史归档会导致 OOM。本实验将该归档移至 CPU，继续以 float32 精确保存；仅把采中的历史传回 GPU。归档槽数 4、间隔 200 步、配对资格、采样 RNG 和模型计算均保持不变，活跃的短期与长期记忆仍位于 GPU。CPU/GPU 往返逐元素一致性有独立测试。

不设更新上限。`--updates 8000` 只定义余弦学习率周期，到期后沿用最低学习率 `1e-5`，直到用户停止。W&B project 为 `intact-forward-predictor`，group/name 均为 `144000-exp-heavy`。

运行配置、数据清单、原训练停止记录、启动验证及日志保存在 `runs/144000-exp-heavy/`。正式入口为 `intact_tracking.cli.forward_memory_proprio_heavy_train`，启动脚本为 `scripts/run_144000_heavy_context.py`。
