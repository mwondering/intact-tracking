# DR-center u8250：收敛趋势与后续损失建议

2026-09-15 14:30:53 UTC 启动检查时，最新完整保存的 checkpoint 为八卡、表征权重 0.04 的 u8250。训练仍在继续，本次未改动训练损失、学习率或停止条件。

结论：在当前损失和学习率下已经接近平台期。更长区间仍有小幅收益，不能宣称严格收敛或证明现有目标已达到最优；继续原配置训练对跨 motion 紧凑性的改善很有限。建议优先试验同 DR、不同 motion 的弱正约束，DR 距离映射作为后续小幅调整。

按查询 world 配对 bootstrap，u7500→u8250：

- DR＋负载 Top-1 **+0.70 个百分点**，95% 区间 **[−0.04, +1.40]**。
- 普通 DR Top-1 **+0.13 个百分点**，95% 区间 **[−0.84, +1.05]**。

两者均不能区分于本诊断集上的零增益。较长的 u6000→u8250 区间，负载组仍有 **+1.52 个百分点**，区间 **[+0.35, +2.74]**；普通 DR 为 **+0.79 个百分点**，区间 **[−0.53, +2.12]**。因此描述为接近平台、仍有小幅收益，比“完全不再学习”准确。区间衡量当前固定 world 的抽样不确定性，不包含重新训练的随机性。

同一八卡固定验证集，6500–6900 与 7800–8200 两个等长窗口的平均 DR 五步 NMSE 从 **0.022612→0.022290**，只下降约 **1.42%**；中心关系损失 **0.013497→0.013303**。u7500/u8250 的学习率均为 **1e-5**。平台判断限定在当前损失和学习率下。

|---|---:|---:|
| 最近异环境中心距离，按中心平均 | 0.4333 | 0.2051 |
| 查询到正确环境中心距离，按查询平均 | 0.3979 | 0.3506 |

平均异 DR 样本对距离较大，不代表每个邻近环境都可辨。上述半径与中心间距只用于描述尺度；高维中噪声方向也影响分类，不能由半径直接推出重叠概率。诊断脚本同时计算精确分类距离与决策 margin，并逐项复现 Top-1。

## 弱正样本建议

当前代码对同一 world/session 的两个不同 motion 视图求平均中心，再监督中心之间的 DR 参数距离。单条视图到中心的偏移、两视图之间的距离只记录指标，不进入损失。中心关系存在间接影响，但没有直接惩罚较大的跨 motion 散布。

建议新增：

\[
L_{\mathrm{DR+}} = \operatorname{mean}_{\substack{\text{同 DR、同 physics session}\\\text{不同 motion、完整且不重叠历史}}}
\|z_i-z_j\|_2^2.
\]

沿用现有 archive 和有效性筛选，每次使用当前 encoder 重算两个视图。只在有效 DR 配对内平均，不被 nominal50 稀释；64 维差异先求平方和，再按配对平均。无需额外中心网络或新增半径项。正样本聚合与同类拉近原则可参照 [Supervised Contrastive Learning](https://arxiv.org/abs/2004.11362)，但本实验继续用物理参数距离监督不同环境，而不是照搬其离散分类负样本。

起始试验可用 `L = L_predict + 0.04 L_DR-center + 0.001 L_DR+`；若拉近作用不足再测 0.002。这是待验证的起始系数，不是已经测得的最优值。需记录梯度贡献、跨 motion Top-1/Top-5、簇内距离和 predictor NMSE，防止只看正样本损失下降。

## 距离映射是否需要调整

现用 `target(d)=2d/(d+0.3)`。本诊断集在相同已知环境中心集合上，仅重新计算目标值，有：

| scale | DR＋负载平均目标距离 | 普通 DR 平均目标距离 |
|---|---:|---:|
| 0.30 | 1.136 | 0.993 |
| 0.25 | 1.223 | 1.083 |
| 0.20 | 1.325 | 1.190 |
| 0.10 | 1.593 | 1.489 |

当前对应的实际平均中心距离为 **1.047 / 0.759**，原目标尚未完全拟合到。降低 scale 会提高目标，但不保证实际距离或识别率按比例提高。映射的斜率为 `2s/(d+s)^2`，改变 s 也会改变近距离和远距离区间的相对分辨率。

优先试验弱正约束时建议 scale 保持 0.3。若后续要调整，可先测 **0.3→0.25**，目标平均增幅约 7.7% / 9.0%，避免同时大幅提高中心关系系数。

不建议直接降到 0.1：当前中心为单位 latent 的均值，范数≤1。N 个中心的平均成对平方距离最多为 `2N/(N−1)`，故平均距离最多约 **1.417**；上述 0.1 映射在两组中的平均目标均超过这个上界。单个距离可接近 2，不代表数百个中心之间都能接近 2。该上界不保证其他 scale 的目标几何一定可实现，但足以否定本集合上 0.1 的全部配对精确拟合。
