# 单 motion、5 步仿真预览：初步结论

2026-09-07 10:41 UTC；当前是第一阶段。不是最终300轮验收，也不是跨motion泛化结论。

## 结论

目前已验证预览能进入 actor 和 critic，critic 也确实对它产生响应；但在
当前普通拼接/MLP结构下，尚未观察到明确的平均tracking收益，远未达到nominal目标。
不能把普通DR residual相对冻结tracker的提升，归因于预览先验。
这个结果不等于证明仿真先验无用，只是否定“接上输入就已显著改善”的表述。

## 实验约束与结构

- 单条 `lafan_qingtong/dance1_subject2.motion.npz`，6574帧，事先选定。
- 三组同源冻结tracker；前端仍是原来的可部署/估计输入，不使用额外oracle替换。
- 当前状态/接触/实际物理参数566维 + 共同未来参考355维 + 未来结果720维。
  真实/屏蔽组总维度均1641；只有最后720维不同。两组都实际运行仿真分支。
- 每次从residual实际到达的状态、历史、参考时刻及实际DR物理重新分支。
  分支连续5步，每步重算冻结tracker动作，不保持首步动作、不查询residual未来动作。
  未来状态和有符号目标误差、body/joint距离作为当时的PPO观测保存。
- Actor:1641→256→128→64；latent与冻结tracker特征进入512/256/128 residual。
- 新critic:原6330→1024→512→512→1价值分支，加上7971→256→128→1修正分支。
  新分支读取与actor完全相同的1641维观测，参数/归一化独立；屏蔽在两者读取前完成。
  初始修正分支输出为零，初始价值预测与原critic完全相同。Critic两条分支均可学习。
- 原奖励完全不变，SHA
  `abee73632d079f08c160584b04ace15532ecf6bd9dfa8139979af518d8a1553c`。
  无奖励塑形、辅助奖励、world model或PD/力矩上限改动。
- 配对训练seed121，512env×24步，LR actor1e-4/critic5e-4，critic预热20轮。
  当前主表checkpoint100实际完成101轮更新；300轮最终点预先固定，仍在运行。
  三组初始actor及critic各张量逐位相等；到100的冻结tracker各张量未改变。
- 所有residual共享已经预训练的tracker，因此不是“从零nominal/DR训练”的比较。

## 同步给 actor 和 critic 的主比较

同一测试seed13001，128个固定起点/物理世界，每片段最多500步。DR行均在DR中测；
nominal目标单独在nominal中测。不同训练组的起点、物理指纹、参考时刻已核对。

真实/屏蔽预览：body高0.358%，joint低0.318%。条件于本motion及checkpoint的
配对world/start bootstrap比值95%区间为：body[0.99539,1.01123]，
joint[0.99296,1.00052]，均包含1。区间不代表跨训练seed或跨motion不确定性。
避免了唯一的失败（世界111，起点5259；冻结tracker也在这里失败），无新增失败。
但0对1次失败不足以证明可靠的失败率下降。

相对冻结DR tracker，真实预览组body/joint低6.92%/1.99%；但同样训练的屏蔽组
也有类似提升。相对既有固定nominal参照仍高55.66%/35.24%，第一阶段未完成。
相对同架构、本motion训练的nominal对照仍高62.92%/40.21%。这比既有固定nominal
参照更严格；两种比较都远未达到目标。

## 网络是否使用预览

独立于质量评测的AC checkpoint50输入干预：只屏蔽或错配最后720维，保留当前状态、
物理参数及参考。屏蔽后critic输出RMS变化0.2114，错配后0.1916；原value STD约1.684。
Actor对应变化0.001699/0.002086。两者对未来结果输入均有非零梯度。
这证明功能依赖，**不证明价值预测更准确或策略训练更有效**；干预输入也可能离分布。

## 仿真数值误差

真实状态/历史/RNG不受分支查询影响；实际随机化物理字段一致，参考和首步动作一致。
接触附近不能逐位重放。512world×8次×5步检查中，最差批次平均预览误差/实际tracking
误差比例：body约0.00121%、joint约0.00165%；极值body点1.614mm、joint向量0.00708rad。
曾设定的1mm/0.005rad极值门槛未通过，原JSON保留false；用户明确允许足够小的非零
重复误差后，继续验证这种有数值误差的仿真预览。没有修改求解器或奖励来改善检查。
速度分量存在更大的极端偏差，因此不宣称高精度速度预言器。
