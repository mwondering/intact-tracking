# u12000：10 步与 5 步响应标签直接对比

两组 predictor 都监督 5 步；以下 Top1/Top5 使用跨 motion family、历史不重叠的固定划分。

|条件|5 步 Top1|10 步 Top1|Top1 差异（百分点）|配对 world bootstrap 95% 区间|5 步 Top5|10 步 Top5|
|---|---:|---:|---:|---:|---:|---:|
|普通 DR（409 中心、3152 测试样本）|26.65%|26.46%|-0.19|[-1.38, +0.97]|50.41%|50.79%|
|DR＋负载（292 中心、2761 测试样本）|79.03%|80.48%|+1.45|[+0.33, +2.62]|93.26%|93.26%|

距离均为 L2 归一化 latent 的欧氏距离 RMS；簇内距离要求跨 motion、历史不重叠。

10 步在 DR＋负载识别上有小幅收益；普通 DR 的识别率接近，但同环境的跨 motion 距离增大得更快。

识别率衡量已知环境在另一组 motion 上的中心迁移。Bootstrap 只衡量本固定诊断集的不确定性，不能代替多训练种子验证。

10 步组在 u11000 恢复；5 步组连续训练至 u12000，因此还包含恢复时点和采样轨迹差异。继续至 u15000 再选型。
