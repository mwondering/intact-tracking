# Memory350 residual PPO 对比结果

跨 reset、已有长期记忆：共同有效时段 body/joint 误差相对 baseline 分别降低 -0.27% / -2.21%；失败率变化 +0.22 个百分点。

冷启动、初始无记忆：共同有效时段 body/joint 误差相对 baseline 分别降低 -1.87% / -2.86%；失败率变化 +0.17 个百分点。

尚不满足两个主要场景均改善且失败率未上升的严格判据；需分别解释误差、失败率与置信区间。

这是单个配对训练 seed 的结论，bootstrap 区间只反映测试动作的不确定性。

两组均完成 5000 PPO updates；每组 2 卡、每卡 8192 环境，全 129827 条 motion。冻结 tracker 原始 DR + 双手及小腿中部各独立 U(0,4 kg)，1000-step episode，训练关闭 ee_body_pos termination；评估沿用冻结 tracker 原始失败条件。

每项评估含 4096 个固定配对 motion/start/physics。warm 场景先用同一个冻结 tracker 按相同 seed 收集 500 步，再 reset 到测试起点。接触仿真不保证逐位确定性，实际 warm 轨迹摘要均保留。
