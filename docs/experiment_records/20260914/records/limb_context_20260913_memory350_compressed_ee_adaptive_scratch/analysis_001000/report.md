# Baseline 与 latent：第 1000 轮对比

本次使用两组从零、直接 adaptive、启用末端高度终止的压缩观测 PPO，核对精确 u1000 checkpoint 和已完成的自动固定评测。共 512 条固定 motion，每条最多 1000 个控制步。0/4 kg 为每肢附加负载，两组都保留 tracker DR；0 kg 不等于 nominal 环境。

冷启动从空历史开始；热启动先用同一冻结 tracker 收集 500 步历史，再回到配对 query 状态评测。Body/joint 误差只计算双方都未结束的共同有效时段；其余误差按各自有效步数汇总。区间按 motion 配对 bootstrap，不包含训练 seed 波动。

|---|---:|---:|---|---:|---:|---|
| 每肢 0 kg，冷启动 | 4.338 | 3.488 | +19.60% [+18.42, +20.77] | +13.07% | 1→1 / 512 | 99.88%→99.90% |

误差降幅为正表示 latent 更好。0 kg 的 body 误差约降低 19.6%，joint 约降低 12.8–13.1%。4 kg 的 body 误差高 1.7–2.3%，joint 高 1.5–1.8%；该子集的配对区间均未跨零。4 kg 失败率两项均低 1.17 个百分点，但其配对区间含零，暂不能确认失败率改善。当前结果体现指标取舍，不能据此认定 latent 已取得全面优势。
