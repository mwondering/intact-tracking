# Memory350 encoder 扩容：20000 轮检查

仅比较当前 nominal50 两组：encoder 1,035,328 → 2,026,688 参数，三段深度 1/2/2 → 2/4/4；predictor 19,059,798 参数、64 维 latent 和其他训练设置相同。两组均为完整数据集、50% nominal + 50% tracker DR/四肢 U(0,4 kg)。

使用同轮 checkpoint、相同归一化和固定验证轨迹；2048 窗口、495 个验证 world，其中 DR 1030 窗口/249 world，nominal 1018 窗口/246 world。下面 NMSE 由所有对应窗口合并计算，和四 rank 平均的训练曲线口径略有区别。

| 轮次 | DR 原版 NMSE | DR 扩容版 NMSE | DR 误差降低 | Nominal 误差降低 |
|---|---:|---:|---:|---:|
| 5000 | 0.04118260 | 0.03586603 | +12.91% | +1.76% |
| 7500 | 0.03555308 | 0.03446283 | +3.07% | +7.50% |
| 10000 | 0.03534863 | 0.03349094 | +5.26% | +5.78% |
| 15000 | 0.03439456 | 0.03290720 | +4.32% | +9.07% |
| 20000 | 0.03387464 | 0.03248816 | +4.09% | +6.48% |

当前结论：五步均值有小幅收益；DR 的 95% 区间包含没有改善，nominal 的区间支持改善。一阶段同轮比较尚未到预先固定的 22700 轮；目前仅一个训练种子。Bootstrap 只描述固定验证 world 的不确定性，不代表跨训练种子复现。

10000–20000 轮的 101 个对应日志点，DR 平均误差降低 4.21%，nominal 降低 7.05%。这是重复使用同一验证集的趋势，不应作为独立重复实验。

DR 一步误差 0.03658812 → 0.03996810，反而升高 9.24%。深度扩容不是所有预测步长和历史状态都改善。扩容版尚未做 residual PPO 对照，因此不能推断 tracking 已提高。
